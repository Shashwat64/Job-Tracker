# OfferPath — Job Application Tracker

A full-stack web application to track and manage your job applications in one place.

🔗 [Live Demo]([your-live-link](https://job-tracker-ten-plum.vercel.app/))

---

## Features

- User authentication with JWT and HTTP-only cookies
- Add, edit, and delete job applications
- Track status — Applied, Interview, Offer, Rejected
- Dashboard with application stats
- Resume upload and storage
- Filter and search applications

## Tech Stack

**Frontend:** React, TypeScript, React Router, Tailwind CSS  
**Backend:** Node.js, Express, TypeScript  
**Database:** PostgreSQL (Neon)  
**Storage:** Cloudinary  
**Deployment:** Vercel (frontend) · Render (backend)


## Running Locally

```bash
# Frontend
cd frontend
npm install
npm run dev

# Backend
cd backend
npm install
npm run dev
```
